# Third-party distribution notes

Qwen3-8B-MLX-4bit, Qwen3-8B-AWQ, and NVIDIA Qwen3-8B-NVFP4 identify their model
licenses as Apache-2.0. Model provisioning retains each repository's LICENSE and
README. Preserve applicable notices and identify modifications if redistributing
weights. Apache-2.0 does not provide trademark endorsement. Check the actual
downloaded license for the pinned snapshot before a customer release.

- [Qwen MLX model](https://huggingface.co/Qwen/Qwen3-8B-MLX-4bit)
- [Qwen AWQ model](https://huggingface.co/Qwen/Qwen3-8B-AWQ)
- [NVIDIA NVFP4 model](https://huggingface.co/nvidia/Qwen3-8B-NVFP4)
- [Apache license](https://www.apache.org/licenses/LICENSE-2.0)

The source preview downloads dependencies and images during setup. A future
offline bundle that redistributes Python wheels, Redis, CUDA/vLLM images, or native
Metal runtimes needs an inventory of their licenses and included notices. This
archive does not select a distribution license for Apartmint's original code.
